## 完整示範

- 在獨立目錄依 README 執行驗證、合成與混音，從所附音檔重建成片。
- 完整旁白 52.91 秒，共 15 句；使用者已確認完整旁白與配樂試聽，並授權合成與公開。
- 成片 52.93 秒、1080 × 1920、30 fps、H.264 / AAC；全片解碼通過。
- 8 個原創圖卡來源各使用一次；重複清單為空。
- 聲畫尾差約 0.33 毫秒。整體音量 -17.99 LUFS，真峰值 -4.10 dBTP。
- 人聲整體高於音樂約 18.13 dB；有效一秒視窗的最小差值約 12.38 dB。
- 混音前後解碼畫格一致，人聲成分的數值殘差約 5.6 × 10⁻¹⁷。
- 以不到 5 秒的間隔取樣，檢查全部分鏡及 390 px 手機版面。正常稿完整，字幕無溢出。
- Whisper 全文轉錄作為輔助，少數同音辨識差異保留在檢查資料；正常稿與字幕維持正字。
- 完整音軌試聽核准後再合成影片；最終 AAC 容器經技術驗證，未另宣稱人工重聽最終容器。

## 驗收界線

程式與模型的驗證記錄均以本次環境為範圍。Linux 的完整 BreezyVoice 配音、其他硬體效能、不同人聲樣本、所有新聞題材與長篇穩定性尚未全面驗證。GitHub Actions 的 Linux 核心測試結果以公開倉庫的實際 run 為準。

音訊統計與 Whisper 辨識只能輔助試聽。資料真實性、專有名詞、聲音相似度、情緒、畫面身分與手機閱讀體驗仍需製作者確認。來源唯一性中的變形素材，須以原始來源 ID 與人工核對共同把關。
